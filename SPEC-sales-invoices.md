# Sales invoice module

## Scope

Sales invoices are available only to admin users through the authenticated
AJFAN Documents workspace. Invoice numbers are generated by the backend from
the invoice row ID and rendered as zero-padded values such as `001`, `002`,
and `003`. The number is never accepted from the client.

## API

- `GET /api/sales-invoices/` lists active invoices.
- `POST /api/sales-invoices/` creates an invoice with one or more service lines.
- `GET /api/sales-invoices/<id>/` returns invoice details.
- `PATCH /api/sales-invoices/<id>/` updates invoice details and replaces lines
  when `items` is supplied.
- `DELETE /api/sales-invoices/<id>/` soft-deletes the invoice.
- `GET /api/sales-invoices/staff/` lists active admin users for staff payment
  selection.

Each line stores the selected service, description, sub/government fee, service
fee, quantity, start date, expiry date, and a backend-calculated line total.
The backend calculates subtotal, total, and balance from the line items,
discount, and received amount. Customers and services must be active records.

## Frontend behavior

The `/ajifan-documents` admin workspace contains a Sales Invoice sidebar view.
It supports customer and service dropdowns, repeated service lines, automatic
fee prefilling from the selected service, payment summary, staff payment
selection, search, view, edit, and soft delete.
